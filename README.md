# macros — сайт разработчика

Многостраничная визитка в стиле хай-тек: графитовый фон, холодные акценты, адаптивная вёрстка и motion-дизайн. Чистые HTML, CSS и JavaScript, без сборки и серверной части.

- Сайт: https://macro-vibe.github.io/Visite-site/
- Контакт: https://t.me/BOCKPECHOE

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Представление разработчика с анимированной моделью в фоне первого экрана |
| `services.html` | Единственный каталог: шесть направлений и седьмая карточка для нестандартной задачи |
| `approach.html` | Этапы работы и ответы на практические вопросы |
| `contact.html` | Единственная ссылка на Telegram и краткий бриф |
| `assets/site.css` | Палитра, типографика, адаптивная вёрстка и анимации |
| `assets/site.js` | Перелистывание разделов, история браузера, карусель и анимации |

Примеры интерфейсов иллюстрируют возможности разработки. Они не заявлены как выполненные клиентские проекты. Сайт не содержит вымышленных отзывов или показателей опыта.

## Локальный просмотр

Из каталога репозитория:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для GitHub Pages выберите ветку `main` и каталог `/ (root)`. Все ссылки и ресурсы относительные, поэтому страницы работают и внутри `/Visite-site/`.

## Что менять

Тексты находятся непосредственно в HTML. Общие цвета — в `:root` файла `assets/site.css`. Контакт Telegram указан только на странице контакта. Навигация и подвал также присутствуют в каждой странице — при изменении обновляйте все четыре файла. Карточки услуг находятся только в `services.html`. Ссылка на Telegram находится только в `contact.html`. Седьмая карточка предлагает обсудить нестандартную задачу и ведёт в раздел контакта. Повторных каталогов нет.

Manrope хранится локально в `assets/fonts/` и не требует запросов к Google Fonts. Лицензия SIL Open Font License находится рядом. Остальная графика создана средствами CSS и SVG. Внешние библиотеки и установка зависимостей не нужны.

## Анимации и управление

- На главной анимированная модель встроена в фон первого экрана. На телефоне виден компактный фрагмент справа; отдельного блока с техническими подписями нет.
- Карусель управляется кнопками, горизонтальным свайпом/трекпадом и клавишами ← / →, Home / End при фокусе на области карточек. Содержимое не переключается автоматически.
- На странице процесса текущий этап отмечается при прокрутке, все этапы доступны сразу.
- Разделы переключаются горизонтальным свайпом вне карточек, стрелками внизу экрана, меню или клавишами ← / →. Свайпы и клавиши внутри карусели управляют только карточками. Вертикальная прокрутка длинных страниц остаётся обычной.
- Кнопка включения анимации удалена. Старое сохранённое ручное отключение сбрасывается; системная настройка уменьшения движения учитывается.
- При переходе меняются адрес и заголовок страницы. Кнопки браузера «Назад» и «Вперёд» работают; при возврате восстанавливается вертикальная позиция. Прямые ссылки и обновление страницы поддерживаются.
- Если загрузка раздела не удалась, используется обычный переход по ссылке. Без поддержки View Transitions работает анимация через Web Animations.
- Системное `prefers-reduced-motion` отключает движение. Навигация и карточки при этом остаются доступными.
- Без JavaScript текст, ссылки, FAQ и нативная горизонтальная прокрутка карточек продолжают работать.

## Проверка изменений

```sh
node --check assets/site.js
```

Перед публикацией проверьте все страницы на телефоне и ПК, кнопки карусели, клавиатуру, свайп, ссылки, FAQ и отключение анимации. Горизонтальной прокрутки всей страницы быть не должно.

Исходная версия до этого редизайна сохранена в истории Git: коммит `c370aa6`. Локальная резервная копия также сделана перед изменениями.

Адреса CSS, JavaScript и favicon в HTML содержат `?v=` с первыми 12 символами SHA-256 файла. При изменении этих ресурсов обновляйте версии во всех четырёх страницах, чтобы браузер загружал новые стили и значок.

Версия до горизонтального переключения: `a3fdf25`. Для возврата можно отменить коммит с перелистыванием через `git revert`, не сбрасывая последующие изменения.
