# macros — сайт разработчика

Сайт в стиле хай-тек с обычной вертикальной прокруткой: главная → услуги → процесс → контакт. Чистые HTML, CSS и JavaScript, без сборки и серверной части.

- Сайт: https://macro-vibe.github.io/Visite-site/
- Telegram: https://t.me/BOCKPECHOE

## Файлы

- `index.html` — всё содержимое сайта. Разделы имеют адреса `#home`, `#services`, `#process`, `#contact`.
- `services.html`, `approach.html`, `contact.html` — совместимость со старыми ссылками: переход к соответствующему разделу главной. Старые ссылки на отдельные этапы и карточки тоже поддерживаются.
- `assets/site.css` — оформление, типографика, адаптация и анимации.
- `assets/site.js` — управление карточками, выделение этапа процесса и пауза фоновой модели вне экрана.

Тексты и ссылки редактируются в `index.html`. Палитра — в `:root` CSS. Шрифт Manrope хранится локально, лицензия — в `assets/fonts/OFL.txt`. Внешние библиотеки не нужны.

Иллюстрации показывают возможные решения, а не выполненные клиентские проекты.

## Просмотр и публикация

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. GitHub Pages использует ветку `main`, каталог `/ (root)`. Относительные адреса работают внутри `/Visite-site/`.

Адреса CSS, JavaScript и favicon содержат `?v=` с первыми 12 символами SHA-256 файла. После изменений ресурса обновите его версию в `index.html`.

## Управление

- Колёсико, трекпад, вертикальный свайп и клавиши прокрутки работают нативно. Разделы находятся в одном документе, без подмены содержимого и анимации смены страниц.
- Верхнего меню, стрелок переключения разделов и горизонтальных жестов смены раздела нет.
- Семь карточек услуг листаются своими кнопками, горизонтальными жестами и клавишами ← / →, Home / End при фокусе на карусели.
- В конце каждой карточки — «Обсудить задачу» с прямой ссылкой в Telegram. Контакт также есть в шапке и отдельном разделе.
- Ссылки на этапы процесса прокручивают страницу по вертикали. При отключённом JavaScript содержимое и ссылки остаются доступны.
- Настройка устройства `prefers-reduced-motion` отключает декоративное движение. Фоновая модель приостанавливается вне экрана и в скрытой вкладке.

## Проверка

```sh
node --check assets/site.js
```

Проверьте вертикальную прокрутку в обе стороны, карточки, ссылки на этапы, старые адреса и отсутствие горизонтальной прокрутки всей страницы на телефоне и ПК.
