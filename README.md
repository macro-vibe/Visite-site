# BOCKPECHOE — сайт разработчика

Многостраничная визитка с адаптивной вёрсткой и motion-дизайном. Чистые HTML, CSS и JavaScript, без сборки и серверной части.

- Сайт: https://macro-vibe.github.io/Visite-site/
- Контакт: https://t.me/BOCKPECHOE

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная, анимированная рабочая система, карточки направлений |
| `services.html` | Шесть направлений разработки и примеры задач |
| `approach.html` | Этапы и принципы работы |
| `contact.html` | Telegram, краткий бриф и ответы на вопросы |
| `assets/site.css` | Палитра, типографика, адаптивная вёрстка и анимации |
| `assets/site.js` | Карусель, движение при прокрутке и настройки анимации |

Примеры интерфейсов иллюстрируют возможности разработки. Они не заявлены как выполненные клиентские проекты. Сайт не содержит вымышленных отзывов или показателей опыта.

## Локальный просмотр

Из каталога репозитория:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для GitHub Pages выберите ветку `main` и каталог `/ (root)`. Все ссылки и ресурсы относительные, поэтому страницы работают и внутри `/Visite-site/`.

## Что менять

Тексты находятся непосредственно в HTML. Общие цвета — в `:root` файла `assets/site.css`. Контакт Telegram указан в ссылках всех четырёх страниц. Навигация и подвал также присутствуют в каждой странице — при изменении обновляйте все четыре файла. Список карточек есть на главной и на странице направлений.

Manrope хранится локально в `assets/fonts/` и не требует запросов к Google Fonts. Лицензия SIL Open Font License находится рядом. Остальная графика создана средствами CSS и SVG. Внешние библиотеки и установка зависимостей не нужны.

## Анимации и управление

- Главная композиция движется постоянно, раскрывается при прокрутке и реагирует на мышь на ПК.
- Карусель управляется кнопками, горизонтальным свайпом/трекпадом и клавишами ← / →, Home / End при фокусе на области карточек. Содержимое не переключается автоматически.
- На странице процесса текущий этап отмечается при прокрутке, все этапы доступны сразу.
- Внизу каждой страницы есть кнопка приостановки анимации. Выбор сохраняется локально в браузере.
- Системное `prefers-reduced-motion` отключает движение. Навигация и карточки при этом остаются доступными.
- Без JavaScript текст, ссылки, FAQ и нативная горизонтальная прокрутка карточек продолжают работать.

## Проверка изменений

```sh
node --check assets/site.js
```

Перед публикацией проверьте все страницы на телефоне и ПК, кнопки карусели, клавиатуру, свайп, ссылки, FAQ и отключение анимации. Горизонтальной прокрутки всей страницы быть не должно.
